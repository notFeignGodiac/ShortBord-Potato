### **Shortbot - Windows Release**

Download and save any video from just a link. Each downloaded file is kept in its original downloaded format and resolution.

**What's included**

- Standalone Windows app; users don't need to install Python or FFmpeg.
- Processes links in defu.txt in order, using the existing link-resolution method.
- Saves videos in a videos folder next to the app.
- Remembers completed downloads, skips them on later runs, and continues past failed links.
- Creates defu.txt and default configuration files on first launch without overwriting existing files.

**Getting started**

1. Put Shortbot.exe in a folder where you can save files.
2. Run it once to create defu.txt.
3. Open defu.txt and add one link per line, save the file, and run the app again.

**How to get a video link**

1. Open your desired website.
2. Click on the video you want to download.
3. Copy the link and paste it in defu.txt.

*Use Shortbot only with videos you're authorized to download. Any text or watermark already present in a source video remains in the saved file.*
